# Syntracks Setup

Everything you need to set up Syntracks on a new phone or in the browser.

## What is this?

Syntracks remembers the music from TikTok videos. Share a video or save a link, the server identifies the song with title, artist and album art, and you find everything again in the app or in the browser, with previews and recommendations. Every user has their own account and their own list.

## 1. Install the Android app (the main route)

1. Send this file to your phone or open the link in your phone browser and download it. File: `syntracks.apk` (or use the download link below).
2. Tap the downloaded APK. Android warns about unknown sources, confirm once with **"Install anyway"** or allow the source.
3. Open the app and tap **"Create account"**. Pick a username and a password. Registration is open, no invitation needed.
4. Allow notifications when the app asks, otherwise you will not see which song was identified.
5. Updates install themselves. When a new version exists a banner appears at the top, tap **Update** once. The first time Android asks whether the app may install from this source, allow it.

Saving songs then works like this. In TikTok tap **Share** on the video and choose **Syntracks**. Or **Copy link** and tap **"Save song"** in the notification bar.

## 2. Browser (no installation)

Open https://syntracks.xsyntachs.de and sign in. You only need to create an account once. Same list as in the app, with previews, search, filters and statistics.

## 3. iPhone

There is no iOS app, the route runs through an Apple Shortcut. Open https://syntracks.xsyntachs.de/ios on the iPhone, sign in and follow the steps. Afterwards Syntracks sits in the TikTok share sheet.

## 4. Install the Chrome extension

The extension puts a save button right next to the share button on tiktok.com.

Install it from the Chrome Web Store so updates arrive by themselves:
https://chromewebstore.google.com/detail/hlecjdomfgbhajgeepojmobogolpcllg

Afterwards pin the icon in Chrome (puzzle icon, then the pin next to Syntracks) and sign in once in the popup.

If you prefer to load the `chrome_extension` folder by hand, enable **Developer mode** under `chrome://extensions` and click **"Load unpacked"**. That route gets no automatic updates.
